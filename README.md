# Aviral Gupta Portfolio — Minimal Clay Refinement

This refinement preserves the existing page structure, copy, header, footer, and claymorphism design. It focuses on more legible heading/body colors, a calmer blue-lavender palette, consistent existing icon treatments, and clearer light/dark theme contrast.

## Files
- `index.html` — portfolio markup and all existing content
- `styles.css` — layout, claymorphism, responsive styling, and refined theme colors
- `script.js` — theme toggle, mobile navigation, and reveal effects

## Run locally
Open `index.html` in a browser, or serve the folder using a local static server. For GitHub Pages, upload all three files to the repository root.

Please verify phone number and social links before publishing.
